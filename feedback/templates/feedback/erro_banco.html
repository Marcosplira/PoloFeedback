O banco ainda não está pronto

A aplicação não conseguiu consultar o banco. Isso costuma acontecer quando as migrações não foram executadas no mesmo projeto e banco usados para iniciar o servidor.

Corrija no computador que está rodando o site

  1. Pare o servidor com Ctrl+C.
  2. Abra o terminal na pasta que contém o arquivo manage.py desta aplicação.
  3. Execute python manage.py migrate.
  4. Inicie novamente com python manage.py runserver.

No Windows, use o mesmo Python/ambiente virtual que inicia o servidor. Se houver cópias do projeto em Downloads e Desktop, aplique a migração na cópia que contém o manage.py ativo. Não apague o banco de dados.
